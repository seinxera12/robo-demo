Place your icon file here as:
  assets/icon.ico

The icon is referenced by DemoVoiceAssistant.spec and installer/DemoVoiceAssistant.iss.
If no icon is provided, remove the icon= lines from both files before building.

Recommended icon size: 256x256 px, saved as a multi-resolution .ico
(16, 32, 48, 64, 128, 256 px layers).
